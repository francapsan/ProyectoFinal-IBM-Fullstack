Innovación Automotriz & Cloud Native

Conectando Conductores con la Excelencia

AutoPulse es una plataforma web híbrida de microservicios diseñada para revolucionar la gestión, descubrimiento y evaluación de concesionarios de automóviles en todo el país.

Nuestra infraestructura combina la robustez y seguridad de Django (Python) para la capa de gestión y autenticación empresarial, con la agilidad asíncrona de Express.js y MongoDB para el procesamiento masivo de reseñas, complementado con un microservicio de Analizador de Sentimientos con Inteligencia Artificial para calificar objetivamente la experiencia de cada cliente.

Arquitectura del Sistema

  • Django Monolith Front-Controller: Manejo de usuarios, sesiones seguras, catálogo relacional de marcas y modelos (Car Makes & Models), y panel administrativo.
  • Express + MongoDB Microservice: Persistencia NoSQL de alto rendimiento para concesionarios y reseñas sin esquemas rígidos.
  • Microservicio de Analizador de Sentimientos: Clasificación algorítmica de reseñas en Positivas, Neutrales o Negativas mediante procesamiento de lenguaje natural (NLP).
  • Cloud Native & DevOps: Contenerizado con Docker, orquestado con Kubernetes y preparado para despliegue automatizado con GitHub Actions en IBM Cloud Code Engine.
Reseñas Verificadas

Cada reseña puede vincularse a compras reales de modelos específicos de automóviles para garantizar la fiabilidad del feedback.

Análisis de Sentimiento IA

Determinamos automáticamente el sentimiento del comprador permitiendo identificar al instante la reputación de cada concesionario.

Cobertura Multiestatal

Búsqueda y filtrado dinámico por estados de EE. UU., facilitando la localización del concesionario más conveniente.
